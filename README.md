# Professional Portfolio — GitHub Pages

A responsive, modern portfolio built with HTML, CSS and JavaScript.

## Personalize before publishing

1. In `index.html`, replace `[Your Name]` (twice).
2. Replace `https://www.linkedin.com/` with your LinkedIn profile URL.
3. Replace `https://github.com/` in the contact section with your GitHub profile URL.
4. Replace `your.email@example.com` with your professional email.
5. Replace the three **Add project link** URLs with the corresponding repository links. Until then, the buttons point to GitHub's homepage.
6. Review all skills, project descriptions, degree names and experience claims to ensure accuracy.
7. Optional: add a real headshot, CV PDF and screenshots of your projects later.

## Publish on GitHub Pages (no terminal required)

1. Sign up or sign in at https://github.com/.
2. Create a **public** repository named `YOUR_USERNAME.github.io` (replace YOUR_USERNAME with your exact GitHub username).
3. Open the repository, choose **Add file → Upload files**, and upload `index.html`, `styles.css`, and `script.js` from this folder (upload the files themselves, not the enclosing folder).
4. Commit the changes.
5. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then **Save**.
6. Wait a few minutes, then open `https://YOUR_USERNAME.github.io/`.

To edit later, click a file in your GitHub repository, use the pencil/edit icon, make changes and commit. The website updates after deployment.
