# Laura Florez — Professional Portfolio

Updated portfolio including university education and three completed TripleTen learning stages.

## Update GitHub Pages
1. Open https://github.com/lauraflorezTECH/lauraflorezTECH.github.io
2. Choose Add file → Upload files.
3. Upload `index.html`, `styles.css`, and `script.js` from this folder (not the ZIP).
4. Confirm replacement and commit the changes.
5. Wait for deployment and refresh https://lauraflorezTECH.github.io/ with Ctrl+F5.

University dates, certificate links, LinkedIn, email, and individual project URLs have not been invented. Add verified details later.
