Upload `index.html`, `styles.css`, and `script.js` to the root of the existing GitHub Pages repository, replacing the current files, and commit. Keep Settings > Pages set to main / (root).

Before sharing publicly, verify external project links are viewable by recruiters and contain no confidential or personal information.
