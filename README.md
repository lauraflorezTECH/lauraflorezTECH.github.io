# Laura Florez — Professional Portfolio

Light-blue, white and gold portfolio for GitHub Pages.

## Update your published website
1. Open https://github.com/lauraflorezTECH/lauraflorezTECH.github.io
2. Select Add file → Upload files.
3. Upload `index.html`, `styles.css`, and `script.js` from this package to the repository root.
4. GitHub will ask to replace the existing files; confirm and select Commit changes.
5. Wait for GitHub Pages to deploy and refresh https://lauraflorezTECH.github.io/.

The portfolio currently uses confirmed name and education themes, but does not include a portrait, unverified institution names, certification claims, or unconfirmed contact details. Add your verified LinkedIn, email, certificates and project URLs before using it for applications.
